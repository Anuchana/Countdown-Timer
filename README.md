# MoraSpirit Web Pillar Recruitment Task 02 — Simple Countdown Timer

This repository contains the solution for the MoraSpirit Web Pillar Recruitment Task 02. The goal of this task is to build a "coming soon" style landing page with a live countdown timer.

## Project Structure

- `countdown-timer/`: Contains the Next.js (App Router) + Tailwind CSS application implementing the countdown timer.
- `countdown-timer-work-guide(1).md`: The initial work guide/instructions for the task.

## Features

- **Live Countdown Timer**: Displays Days, Hours, Minutes, and Seconds remaining.
- **Date/Time Picker**: Allows users to set a custom target date and time.
- **Time is up! State**: Displays a dedicated message when the countdown reaches zero.
- **Responsive Design**: Built with Tailwind CSS to ensure a great experience across desktop and mobile devices.
- **Modern Tech Stack**: Uses Next.js App Router and TypeScript.

To get started, navigate to the `countdown-timer/` directory and check its `README.md` for setup instructions.
